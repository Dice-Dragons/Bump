# Changelog - [DD] Bump

All notable changes to this add-on will be documented in this file.

## [1.0.0] - 2026-08-06

### Added
- First stable Gold release of `cv6/Bump`.
- Symfony Console CLI command (`cv6:bump` / `dd:bump`).
- VersionCalculator service supporting semantic bumps (major, minor, patch, alpha, beta, rc, stable).
- Automatic `addon.json` and database version sync.
